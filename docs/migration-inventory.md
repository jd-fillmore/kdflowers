# KD Flowers — Gatsby to Astro Migration Inventory

Audit date: 2026-10-31
Source project: Gatsby 2.28.1 (React 16, SCSS, reactstrap, react-image-gallery)
Production site: https://www.kdflowers.ca/
Production host: Netlify (`kdflowers.ca` 301 → `www.kdflowers.ca`)
Migration status: complete. The Astro app now lives at the repository root; the
original Gatsby project is archived unchanged in `gatsby-legacy/`.

## 1. Existing site summary

- 21 page files in `src/pages` (20 indexable routes + the 404 page).
- One reusable page composition: hero, intro, about, process, testimonial, CTA.
- 14 location-specific wedding-flower landing pages generated from the same
  composition with city-specific copy.
- One portfolio gallery at `/portfolio/` using `react-image-gallery` with 18
  photographs and no per-image alt text in the source.
- No standalone About, Contact, service-index, or individual gallery routes
  existed. The only "About" content was a homepage section.
- No forms were present. The primary conversion action is an external Calendly
  booking link (`https://calendly.com/kdflowers/free-consult`).
- No footer component existed. The CTA section contained the service-area links
  and the "Website by Infused Agency" credit plus six external agency links.
- No canonical tags, Open Graph images, Twitter images, JSON-LD, or robots.txt
  were present in the Gatsby output.
- The XML sitemap was generated by `gatsby-plugin-sitemap` using
  `https://kdflowers.ca` URLs (which redirect to `https://www.kdflowers.ca`).
- The Gatsby manifest/favicon used the Gatsby starter icon, not the KD Flowers
  logo.

## 8. URL and redirect policy

- All existing indexable URLs are preserved exactly, including the trailing
  slash convention used by the live sitemap.
- The production host is `www.kdflowers.ca`; all canonical, sitemap, Open Graph,
  and llms.txt URLs use that host. The apex domain's existing Netlify 301 to
  `www` is unchanged.
- `/consult/` remains available at its original URL but canonicalises to
  `/book-consult/` because the two pages are duplicates. `/consult/` is excluded
  from the XML sitemap.
- `/wedding-flowers-jordan-on/` is the only legacy URL requiring a redirect
  because it never existed as a page; it was a broken link to
  `/wedding-flowers-jordan-ontario/`.
- No new city landing pages were created and no fictional branch locations were
  introduced.
